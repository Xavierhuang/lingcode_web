What's inside

☁

Deploy to web with one button

Hit Deploy in the top-right of the window. Your project goes live on a public URL — straight from the editor. Zero config, zero CLI.

✦

Claude chat, in the editor

A side panel that drives the claude CLI in print mode — so it uses your existing Claude subscription, not a metered API key. Claude can read, edit, and create files scoped to the project root.

⇧

Syntax highlighting, 11 languages

C, Python, JavaScript, HTML, CSS, JSON, PHP, Makefile, shell scripts.

⌘F

Find that gets out of the way

⌘F slides a search bar above the editor with a live match count. ⌘G / ⇧⌘G to step through. No floating panel, no modal, no friction.

⌥

Tiny and native

Native Cocoa. Arm64, signed, single-window, instant launch. The whole app weighs under 2 MB.

Get it running

One DMG. Drag to Applications. Done.

01

Download the DMG

LingCodeBaby.dmg — Apple Silicon, ~2 MB.

02

Drag to Applications

Open the DMG and drag LingCodeBaby.app into the Applications folder.

03

Launch

Double-click LingCodeBaby.app. It opens straight away.

On Windows & Linux

⊞

Windows

Run the _x64-setup.exe (or _arm64-setup.exe) installer. First launch may show a SmartScreen prompt — click More info ▸ Run anyway.

🐧

Linux — AppImage

chmod +x LingCodeBaby_1.0.0_amd64.AppImage then run ./LingCodeBaby_1.0.0_amd64.AppImage.

🐧

Linux — deb / rpm

sudo dpkg -i LingCodeBaby_1.0.0_amd64.deb on Debian/Ubuntu, or install the .x86_64.rpm on Fedora/RHEL.

How to use it

Three steps from blank window to live URL.

01

Open your project folder

File ▸ Open Folder… (or ⌘⇧O). Pick the directory you want to work in — the sidebar lists every file.

02

Prompt Claude

Type into the Claude panel on the right and hit Send. Claude reads, edits, and creates files scoped to your project root.

03

Deploy

Click Deploy in the top-right of the window (or ⌘⇧D). Your project goes live on a public URL — LingCode opens it for you.
