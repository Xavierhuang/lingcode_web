— 你能做什么

选你要做的事，路径已经铺好。

这些需求通常意味着把 IDE、AI 工具、后端服务商、托管和支付拼在一起，再长期维护那些接缝。在这里是一套方案、一个登录、一张账单，接线的活交给 Agent。

SaaS

做一个 SaaS：注册、订阅、自己的域名。

账号、数据、托管站点和周期性收费都在同一个控制台里，任何一项都不需要第二家供应商。

  1. npm create lingcode，或直接打开你已有的项目。
  2. Agent 配置 Postgres 与认证：邮箱、魔法链接、Google、GitHub、Apple，可选多因素。
  3. 在控制台添加商品与价格，调用 client.payments.checkout() 支持银行卡、Apple Pay 与 Google Pay。
  4. npx lingcode ship 上线，绑定你的域名，事务邮件已经就绪。

// 纯 HTTPS + JSON，无需安装任何东西。
struct Envelope<T: Decodable>: Decodable { let ok: Bool; let data: T }
struct Todo: Decodable { let id: Int; let title: String; let done: Bool }

let base = URL(string: "https://lingcode.dev/api/cloud/be/\(backendID)")!

func openTodos() async throws -> [Todo] {
  var req = URLRequest(url: base.appending(path: "select"))
  req.httpMethod = "POST"
  req.setValue("Bearer \(anonKey)", forHTTPHeaderField: "Authorization")
  req.setValue("application/json", forHTTPHeaderField: "Content-Type")
  req.httpBody = try JSONSerialization.data(withJSONObject: [
    "table": "todos",
    "filters": [["op": "eq", "col": "done", "val": false]],
    "order": [["col": "created_at", "ascending": false]],
    "limit": 50
  ])
  let (data, _) = try await URLSession.shared.data(for: req)
  return try JSONDecoder().decode(Envelope<[Todo]>.self, from: data).data
}

三条路进来，同一个 Postgres。

  • →从 Swift 或 Kotlin。 用 URLSession 调用 /api/cloud/be/<id>/…，带 anon key，或带已登录用户的 token 让 RLS 生效。与 JS SDK 封装的是同一组端点。
  • →从 Agent。 lingcode-cloud MCP 服务器上的 56 个工具：provision_backend、apply_migration、set_auth_provider、upsert_function、send_push、vector_search 等。说一句"要一张表"，得到一份带 RLS 的迁移。
  • →从任意终端。 npx lingcode 初始化项目，npx lingcode ship 让它上线。需要 Node 20+。
  • →要走？ 它就是标准 Postgres。导出数据，改一个连接串。

— 实打实的 AI 安全

AI 改动毁不了你的项目。

IDE 留着每一张凭据。每次编辑都被捕获、比对、可回退——Agent 可以放开手干，你不用提心吊胆。

◰

编辑前快照。

Agent 动 project.pbxproj、Info.plist、Gradle 文件或 entitlements 之前，LingCode 先给它们拍快照。改坏了？一键还原。

⇄

按 hunk 审阅。

diff 逐块展示。接受好的，拒绝可疑的。Agent 绝不会悄悄重写你没打开的文件。

⟲

语义化时间回溯撤销。

撤销不是逐个按键，而是逐个提示词。"我让 Agent 加通知，结果跑偏了"——整段一次回退。Agent 还能在隔离的 worktree 里运行，跑坏了也碰不到你的检出。

⌘

原生，不是 Electron。

真正的 AppKit + SwiftUI。在一个 71 个文件的 iOS 工程上，空闲内存 123 MB、CPU 0.2%，Cursor 为 235 MB 与 0.8%——M4 上实测，方法已公开。Cursor 冷启动更快，我们照实说。

⚙

你的 Key，你的算力。

每一档都可自带 Key——Anthropic、OpenAI、Google、DeepSeek、xAI、Ollama 或任意 OpenAI 兼容端点。Key 留在 macOS 钥匙串，直连你选的提供商。不想管 Key？Pro 与 Max Pro 内含托管推理。

∅

诊断数据不出门。

崩溃与性能诊断使用 Apple 的 MetricKit，只留在你的设备上。没有 Sentry、Crashlytics 或 Bugsnag。报告以可读的 JSON 落在 ~/Library/Logs/LingCode。
