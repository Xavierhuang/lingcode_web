如何用 LingCode Baby 把网站发布上线？

TL;DR：打开项目文件夹，点击工具栏上的 Deploy（或使用菜单 File ▸ Deploy to LingCode Cloud），在浏览器中完成登录，然后选一个子域名。你的站点会上线到 https://yourname.lingcode.app/，自带 HTTPS。无需主机账户、无需部署令牌、无需配置 DNS。再次部署会更新同一个 URL。

做第一个网站，最难的往往不是把它写出来，而是写完之后撞上的那堵墙：主机账户、构建命令、部署令牌、域名服务器——这些都与你的网站本身无关，却横在你和"一个能发给别人的链接"之间。LingCode Baby 把这堵墙压缩成了一个按钮。本教程讲清楚按下它之后到底发生了什么，以及出问题时该怎么办。

先说清楚"部署"的到底是什么，因为不同工具对这个词的含义差别很大。Baby 上传的是你项目文件夹里的文件，并把它们作为网站提供出去。如果你有一个 index.html，它就是首页。这属于静态托管：你的 HTML、CSS、JavaScript 和图片，通过 HTTPS 提供服务。没有服务端渲染，也没有需要配置的构建流程——文件夹里是什么，上线的就是什么。

这是有意为之的取舍。Baby 是那个小而安静的应用：写好站点，按一下按钮，它就上线了。如果你需要构建步骤、需要 Next.js 或 SvelteKit 这类框架、或者站点背后需要数据库，那应该用 Mac IDE 的 Cloud 部署——同样的托管，但机制更完整。

你将学到

  • Deploy 按钮在哪里，以及触发它的两种方式
  • 子域名是什么，该怎么选
  • 上线后的 URL 长什么样，之后如何更新站点
  • 最常见的三类问题，以及各自的解决办法

开始之前

  • 一个 LingCode 账户。不需要提前注册——首次部署时会自动打开浏览器，带你走完整个流程。
  • 一个装着你网站的文件夹。至少要有一个 index.html。如果你是让 Baby 的聊天帮你做的网站，这一步已经完成了。

开始部署

  1. 打开项目文件夹。使用 File ▸ Open Folder… 选择存放网站的文件夹。没有打开文件夹时 Deploy 是不可用的——如果先点了它，Baby 会提示你。

  2. 点击 Deploy。按钮在窗口顶部的工具栏上。如果你更习惯用菜单，同样的命令在 File ▸ Deploy to LingCode Cloud。

  3. 登录一次即可。首次部署时浏览器会打开 LingCode 登录页。在浏览器里完成登录后切回 Baby——它会自动接收结果，不需要复制粘贴任何东西。之后的部署不会再出现这一步。

  4. 选择你的子域名。Baby 会询问站点要用的名字。填一个简短的小写名称——比如 my-portfolio、tea-club，或者你自己的名字。它会变成 https://my-portfolio.lingcode.app/。如果名字已被占用，Baby 会提示并让你重填；在接受一个可用名字之前，不会发布任何内容。

  5. 等待上传。你会看到 Uploading to LingCode Cloud…，然后是 Deploying to LingCode Cloud…。小站点只需要几秒钟。

  6. 打开你的网站。完成后 Baby 会显示 Deployed to LingCode Cloud，附带你的实时 URL 和一个 Copy URL 按钮。这个链接对任何人、任何设备都立即可用，HTTPS 已经配置好了。

之后如何更新站点。修改文件后再次点击 Deploy，沿用同一个子域名即可。原有 URL 会就地更新——不会产生新链接，也不需要再通知任何人。如果浏览器仍显示旧版本，强制刷新一下（⌘⇧R）。

出问题时怎么办

  • 提示需要先打开文件夹。说明当前没有打开项目文件夹。先用 File ▸ Open Folder…。
  • 浏览器打开了，但没有反应。请在浏览器标签页里完成登录，再切回 Baby。如果标签页被过早关掉，再点一次 Deploy 就会重新打开登录页。
  • 提示子域名不可用。说明这个子域名已被占用。名字在所有 LingCode 用户之间先到先得，常用词很快就没了。加个词即可：tea-club-oxford。
  • 页面能打开但是空白。几乎都是 index.html 缺失或名字写错——这个文件必须位于你部署的文件夹的顶层，并且文件名区分大小写。

使用你自己的域名

.lingcode.app 地址是一个真实、长期可用的站点地址，很多项目一直用它就够了。当你确实想用 yourname.com 时，需要先从域名注册商购买域名，再把它指向你的站点——这部分见连接自定义域名；如果你还没有域名，可以从 在 Cloudflare 购买域名或 Namecheap 开始。
