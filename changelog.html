Release notes

Changelog

What shipped, when, across the macOS IDE, the /try playground, the lingcode CLI, and LingCode Cloud.

v2.7.6

14 August 2026 Mac

Improved

  • Internal telemetry — bridge watchdog now emits notice-level breadcrumbs visible in the unified log without requiring sudo log config, so future bridge issues are easier to diagnose from Console.

Fixed

  • Claude Code native tab no longer gets stuck on "Puzzling…" after long sessions — a wedged Node agent bridge is detected via a heartbeat watchdog and restarted automatically, and the Node process is proactively recycled every 25 idle turns.
  • Large file writes no longer get killed with "Claude stopped responding" mid-generation — the stall watchdogs now tolerate long tool-input generation (up to 10 min) instead of the old 90s ceiling that deterministically aborted big Write commands.
  • A frozen app now terminates on Quit instead of hanging until Force Quit — the main-thread watchdog force-exits after 15s of continuous freeze (3s once Quit was requested).

v2.7.5

14 August 2026 Mac

Improved

  • Next-steps suggestions now consider tool activity (files edited, commands run, failures) and no longer re-propose completed work.

Fixed

  • Claude Code web tab's "next steps" suggestions no longer cancel an active AI-panel conversation.

LingCode Cloud

14 August 2026 Cloud

Fixed

  • Deleted LingCodeBaby apps stop serving immediately instead of persisting in the CDN edge cache for minutes.
  • LingCodeBaby deploys from Windows no longer fail with a Node version error.
  • A deploy that fails to mark its app as running now surfaces as failed and rolls back the new container, instead of leaving a healthy container behind a permanent "Building" placeholder.

LingCode Cloud

13 August 2026 Cloud

Added

  • Python app hosting is now functional end to end. Deploys no longer stall in "building" — the Dockerfile generation, container status transitions, and state-directory permission bugs that were blocking it are all fixed.

Improved

  • Saved cloud functions no longer report a per-tier cap.

Fixed

  • A hung deploy no longer stops the runner from picking up later deploys on the same worker. Timed-out deploys now report as failed rather than silently stalling.
  • App lifecycle events — deploy, pause, resume, crash, restart — were being dropped from the observability timeline, and now persist correctly.
  • LingModel returned empty responses when max_tokens was set low; the budget is now capped automatically to leave room for the reply.

v2.7.2

8 August 2026 Mac /try

Added

  • Remote Coding — drive your Mac from the browser at /remote. An embedded SSH server attaches to a Claude Code terminal, and a live-session mirror lets you drive an already-open Claude Code tab remotely. Codex and interactive terminal surfaces are supported too.
  • Claude Code (Web) and Codex (Web) tabs inside the IDE, alongside the existing Terminal and Native tabs.
  • Project sharing with owner / editor / viewer collaborators, project ownership transfer, and an in-browser project editor.
  • LingCode Cloud — a managed backend with a Supabase/Firebase-parity feature set and a management console.
  • Project-local backend-as-code workflows for cloud functions and database migrations, so IDE agents can create, test, update, and deploy cloud functions without opening the backend dashboard.
  • Cloud deploy handles framework-aware SSR, one-click monorepo deploys, and a project deploy manifest.
  • Image attachments preview inline in the Claude composer, the Codex composer, and the unified AI panel.
  • More models and endpoints — GLM-5.2, per-endpoint custom models, and a Fable 5 option.
  • Xcode scaffolding covers tvOS, Rust/UniFFI, and localhost HLS, and generates a unit-test target for new projects. Monorepos get an Xcode project picker, and dev containers support multi-service docker-compose.
  • Editor and terminal quality-of-life — .docx opens as editable rich text with structure preserved, tree-sitter highlighting for C, Objective-C and PHP, a VS Code-style shell-integration context menu, a per-turn fold control for long agent steps, an "Always Allow" option on approval dialogs, and message queueing while the Claude tab is streaming.

Improved

  • Launch is substantially faster — blocking work moved off the main thread, and idle CPU burn and launch-time hangs fixed.
  • The Claude Code tab no longer lags on long conversations. Streaming render, scroll jank, and transcript blanking were all addressed.
  • Agent turns auto-resume after a network reconnect, on the Claude, DeepSeek, and OpenAI-compatible loops.
  • The autonomous agent asks first and checkpoints rather than running away, and chats are scoped per project with unresumable conversations recoverable.
  • The toolbar, activity bar, and bottom tabs now adapt to the project type, the activity bar can be customized, and the provider menus merged into a single AI menu.

Fixed

  • The Claude Code tab no longer goes blank mid-stream or hangs on long bypass-mode turns.
  • Magic Push no longer demands an API key from LingModel users.
  • A Kotlin/Android LSP crash, a Settings window freeze, a stuck Run pulse, a stale run destination that broke ⌘R, and a bottom panel that restored at an unusable sliver height.

v2.7.1

22 May 2026 Mac /try CLI

Added

  • Real-time collaboration on /try and the Mac IDE — Yjs CRDT, live cursors via the awareness protocol, threaded comments anchored to elements, role-based permissions (owner / editor / viewer), and audit-log history. Invite by email or 48-hour share link.
  • Architect spec live panel in the swarm pipeline — watch the JSON spec stream as it's written instead of staring at empty panes for 30 seconds.
  • Chinese parity for /try — full feature set, all 14 toolbar buttons, locale-aware template labels.
  • CLI v0.8.16 with a new auth subcommand and improved doctor diagnostics.
  • SQLite session store on the API server — sessions survive restart, so deploys no longer sign everyone out.

Improved

  • Mac IDE polish — composer keybindings, terminal theming, and build-log ⌘A no longer hijacks chat-input select-all.
  • /try preview iframe respects viewport-mode (Tablet/Mobile) constraints so generated pages can't overflow the simulated viewport.
  • HTML cache headers set Cache-Control: no-cache so deploys reach users immediately, with no hard refresh.

Fixed

  • "Fix with AI" banner removed — it overlapped the prompt area and confused users.
  • The bottom main prompt hides once a session is active, leaving only the per-pane "Ask for tweaks".
  • Focus-mode close button restyled for the light theme, and toolbar buttons no longer overflow the workspace tab bar in focus mode.

v2.7.0

7 May 2026 Mac CLI

Added

  • App Generator Pro tier — full-stack app generation.
  • Monetization — Stripe-backed Pro subscriptions, managed API credits, and an account dashboard.
  • ACP (Agent Coordination Protocol) steps 1–4a — unified HTTP handler, acp-serve CLI subcommand, and MacACPClient.
  • Tool use and MCP across all OpenAI-compatible providers; lingcode serve shipped.
  • Cross-provider max_tokens=32000.

Improved

  • Light mode is now genuinely light — terminal, editor, sidebar, and chrome all flip together when Appearance is toggled.
  • Terminals follow the active code theme, repainting alongside the editor on theme switch.
  • Animated stage progress in the /try preview pane during swarm builds.
  • Tightened the design system — collapsed redundant background tokens and routed status colors through DesignSystem.Colors.
  • Clearer Settings copy — "Color Theme" and "Editor Background Color" now say they only apply when Appearance is set to System.
