What's inside

⇄

FTP and SFTP, native

Save servers once. Reconnect with one click. The classic two-pane workflow without the bloat — listing, upload, download, rename, delete, mkdir.

✦

Claude can move files for you

A side panel that drives Claude with FTP-aware tools. "Push the dist folder to /var/www, back up the old one first" — and it does it, file by file, with progress.

✎

Edit in place, with syntax

Open a remote file, edit it with syntax highlighting (C, Python, JS, HTML, CSS, JSON, PHP, Makefile, shell), save — pushed back automatically.

🔒

Credentials stay on your Mac

Saved server passwords live in your Keychain (where Apple wants them). No cloud sync, no telemetry, nothing leaves the machine.

⌥

Tiny and native

Pure Cocoa, arm64, signed. Single-window per server. Launches instantly — no Electron, no Chromium, no spinning up a 200 MB runtime.

↗

One of the LingCode tools

Part of the LingCode lineup — the full native Mac IDE for AI coding. LingCode FTP is the file-transfer cousin: same DNA, narrower job.

Get it running

One DMG. Drag to Applications. Done.

01

Download the DMG

LingCodeFTP.dmg — Apple Silicon, ~2 MB.

02

Drag to Applications

Open the DMG and drag LingCodeFTP.app into the Applications folder.

03

Add your first server

Launch the app, click ⚙ Settings in the top-right, and fill in host / user / password (or paste an SSH key for SFTP).

Windows & Linux: download the Windows zip (x64 / ARM64) the Linux .deb (x64 / ARM64), or the Linux tarball (x64 / ARM64). Install the .deb with sudo dpkg -i, or extract the tarball and run the LingCodeFTP binary. (Cross-platform build — no installer.)
