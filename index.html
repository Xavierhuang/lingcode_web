Payments

Take payments and stay the merchant.

Stripe processes the money, you own the customer and the payout, and LingCode wires in the catalog, checkout, orders, and refunds.

  1. Connect your Stripe account from the console. Stripe handles identity checks and payouts; LingCode never holds your money.
  2. Create products and prices in the console, one-off or subscription.
  3. client.payments.checkout() opens checkout with cards, Apple Pay, and Google Pay; orders and subscriptions land in your backend.
  4. Starter is included with Pro at a 1% platform fee on top of Stripe's rate. No monthly minimum, no merchant-of-record markup.

// Plain HTTPS + JSON. Nothing to install.
struct Envelope<T: Decodable>: Decodable { let ok: Bool; let data: T }
struct Todo: Decodable { let id: Int; let title: String; let done: Bool }

let base = URL(string: "https://lingcode.dev/api/cloud/be/\(backendID)")!

func openTodos() async throws -> [Todo] {
  var req = URLRequest(url: base.appending(path: "select"))
  req.httpMethod = "POST"
  req.setValue("Bearer \(anonKey)", forHTTPHeaderField: "Authorization")
  req.setValue("application/json", forHTTPHeaderField: "Content-Type")
  req.httpBody = try JSONSerialization.data(withJSONObject: [
    "table": "todos",
    "filters": [["op": "eq", "col": "done", "val": false]],
    "order": [["col": "created_at", "ascending": false]],
    "limit": 50
  ])
  let (data, _) = try await URLSession.shared.data(for: req)
  return try JSONDecoder().decode(Envelope<[Todo]>.self, from: data).data
}

— AI safety, the practical kind

AI edits that can't wreck your project.

The IDE keeps the receipts. Every edit is captured, diffed, and rewindable — so the agent can be aggressive without you losing sleep.

◰

Pre-edit snapshots.

Before the agent touches project.pbxproj, Info.plist, Gradle files, or entitlements, LingCode snapshots them. Bad edit? One key restores.

⇄

Per-hunk review.

Diffs are shown hunk by hunk. Accept the good ones, reject the suspicious. The agent never silently rewrites a file you didn't open.

⟲

Semantic time-travel undo.

Undo isn't keystroke-by-keystroke — it's prompt-by-prompt. Rewind the whole "I asked the agent to add notifications and it went sideways" episode in one shot. Agents can run in an isolated worktree so a bad run never touches your checkout.

⌘

Native, not Electron.

Real AppKit + SwiftUI. On a 71-file iOS project it idles at 123 MB and 0.2% CPU where Cursor sits at 235 MB and 0.8% — measured on an M4, methodology published. Cursor cold-starts faster; we say so.

⚙

Your keys, your compute.

BYOK on every tier — Anthropic, OpenAI, Google, DeepSeek, xAI, Ollama, or any OpenAI-compatible endpoint. Keys stay in the macOS Keychain and go straight to the provider you picked. Prefer not to manage keys? Managed inference is included on Pro and Max Pro.

∅

Diagnostics that stay home.

Crash and performance diagnostics use Apple's MetricKit and stay on your device. No Sentry, Crashlytics, or Bugsnag. Reports land in ~/Library/Logs/LingCode as JSON you can read.
